### 5.2 多空辩论机制

```python
class AgentDebate:
    """多Agent辩论引擎"""
    
    def debate(self, stock_code, data):
        bull_team = [trend_agent, momentum_agent, growth_agent]
        bear_team = [risk_agent, valuation_agent, volatility_agent]
        
        # Round 1: 各自陈述
        bull_args = bull_team.analyze()
        bear_args = bear_team.analyze()
        
        # Round 2: 交叉质询
        rebuttals = cross_examine(bull_args, bear_args)
        
        # Round 3: 最终投票
        final_decision = weighted_vote(bull_team, bear_team, rebuttals)
```
