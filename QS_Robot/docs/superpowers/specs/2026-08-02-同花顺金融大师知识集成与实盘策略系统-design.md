### 3.4 三类选股分流实现

#### StockRecord 扩展
```python
class StockSource(Enum):
    AURORA_NATIVE = "aurora_native"    # 自创策略选股
    VIBE_TRADING = "vibe_trading"      # 港大 Vibe Trading 选股
    THS_IWENCAI  = "ths_iwencai"       # 同花顺问财选股

@dataclass
class StockRecord:
    symbol: str
    name: str
    level: PoolLevel
    source: StockSource                 # 【新增】来源分类
    strategy_name: str = ""             # 【新增】具体策略名
    added_at: str
    last_updated: str
    metadata: Dict[str, Any]
    history: List[Dict[str, Any]]
    backtest_results: List[Dict[str, Any]]
    risk_score: float
    strategy_params: Dict[str, Any]
```

#### 三个独立选股入口
- `select_stocks_aurora_native(strategy_name, count)` — 自创策略选股（已有逻辑改造）
- `select_stocks_vibe(market_regime, count)` — Vibe Trading 选股（新建）
- `select_stocks_ths_iwencai(query, count)` — 同花顺问财选股（新建，依赖 ths_bridge）

#### 统一进股票池带标签
所有股票统一进 WATCHLIST 池，但 metadata 含 source/strategy/selection_path 标签。

#### 三类对比看板
`/stock_pool/source_compare` Tab：展示三类来源在每层池的占比、转化漏斗、平均夏普/胜率/最大回撤。
